## Sobre mí

Soy desarrollador fullstack. Trabajo con React y TypeScript en el frontend, y con Spring Boot o NestJS en el backend.

He llevado un proyecto propio, [Tablaria](https://tablaria.es), desde la idea hasta producción, con tests, revisión de código y auditorías de seguridad. En mis prácticas en The Wise Dreams participé en el desarrollo de un sistema de facturación para una cadena hotelera dentro de un equipo internacional.

Ahora estoy haciendo el curso de especialización en IA y Big Data y busco un puesto fullstack que pueda compaginar con él.

## Proyectos

### [Tablaria](https://tablaria.es) · [código](https://github.com/JonathanTWD/tablaria)
Aplicación web de inventario en tablas personalizables. Proyecto personal de código abierto (MIT).
<br><i>React 19 · TanStack Query · NestJS 11 · Prisma · PostgreSQL · zod</i>

- Diseñado, desarrollado, desplegado y documentado en solitario, en un monorepo pnpm.
- Autenticación con cookies httpOnly y refresh tokens rotatorios con detección de robo.
- Tiempo real con presencia sobre WebSocket, asistente de IA de solo lectura que respeta los permisos del usuario y escáner de QR y códigos de barras.
- Unos 200 tests e2e, tests de accesibilidad con axe (WCAG 2.2 AA) y auditoría OWASP antes de cada release.

### [CanAccesible](https://canaccesible.es) · [código](https://github.com/devcarlosperez/CanAccesible)
Plataforma comunitaria para reportar barreras de accesibilidad en Canarias y consultarlas en un mapa interactivo. Proyecto en equipo de tres personas.
<br><i>React · Express · Sequelize · MySQL · Socket.io · DigitalOcean</i>

- Autenticación y flujos de usuario con JWT: perfil, recuperación de contraseña y correo con Resend.
- Infraestructura de tests del frontend, tests de frontend y backend, y SEO de las páginas.
- Colaboración en el despliegue en un VPS de DigitalOcean.
